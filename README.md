# CS210-Project3
Project Summary

This project is a grocery item tracking program that reads a list of purchased items from a file and analyzes how often each item appears. The program allows the user to search for a specific item, view all item frequencies, or display the data as a histogram. It also creates a backup file to store the frequency data. The main goal of the program was to practice working with file input/output, maps, and building a menu-driven application in C++.

What I Did Well

I think I did a good job organizing the program using a class and keeping the logic separated into functions. Using a map made counting items straightforward and efficient. I also focused on making the program easy to use by keeping the menu simple and making sure each option worked consistently.

Where I Could Improve

One area I could improve is input validation and error handling. While the program works as expected with valid input, it could be more robust if it handled invalid input more cleanly. I could also improve formatting and make the output match a more polished or professional layout. These changes would make the program more reliable and user-friendly.

Most Challenging Part

The most challenging part was making sure the file reading and data storage worked correctly, especially when building the frequency map. I also had to think through how to structure the program so that each menu option could reuse the same data. I worked through this by testing small pieces at a time and using documentation and examples for maps and file handling.

Transferable Skills

This project helped reinforce skills like working with maps, reading and writing files, and structuring programs using classes. These are all things that will carry over to other projects, especially anything involving data processing or user interaction.

Maintainability and Readability

I tried to keep the program maintainable by using clear variable names and breaking the logic into smaller functions instead of putting everything in main. I also added comments where needed to explain the purpose of certain sections. This makes it easier to understand and modify later if changes are needed.
